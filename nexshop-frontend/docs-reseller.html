Apa itu Program Reseller NexShop?

Program Reseller NexShop adalah solusi kemitraan terpadu yang dirancang bagi:

  • Reseller Web / Konter: Langsung belanja di NexShop dengan harga diskon otomatis saat login.
  • Pemilik Website Toko Sendiri / Bot: Menghubungkan website/bot Anda ke API NexShop untuk mengambil katalog, harga reseller, dan menerima notifikasi pesanan otomatis.

auto_graph Konsep Kemitraan

Setelah akun Anda disetujui, harga di seluruh etalase (Marketplace & Topup Diamond Game) otomatis dipotong sesuai tingkatan tier diskon saat Anda login di web maupun saat memanggil API dengan Bearer Token. Anda bebas menentukan harga jual sendiri ke pelanggan untuk mendapatkan margin keuntungan maksimal.

Cara Mendaftar Menjadi Reseller

Pendaftaran program reseller NexShop 100% gratis tanpa dipungut biaya apapun.

1

Miliki Akun NexShop & Login

Pastikan Anda sudah mendaftar dan memiliki akun pengguna di NexShop melalui halaman Masuk / Daftar Akun.

2

Buka Formulir Pendaftaran Reseller

Masuk ke halaman Pendaftaran Reseller, lalu lengkapi: Nama Lengkap, Nomor WhatsApp aktif, Nama Usaha/Website (opsional), Kanal Penjualan, dan Estimasi Transaksi Bulanan.

3

Peninjauan oleh Admin (Maks. 1×24 Jam)

Tim admin NexShop akan meninjau pengajuan dan menghubungi nomor WhatsApp yang Anda daftarkan untuk verifikasi data dan pengaktifan akses reseller.

✓

Status Aktif & Siap Digunakan

Begitu disetujui, akun Anda langsung berstatus Reseller. Anda dapat langsung bertransaksi di web NexShop atau menggunakan API Token untuk website Anda sendiri.

sell Bab 4

Tingkatan Tier & Diskon Reseller

Diskon reseller dihitung otomatis oleh server NexShop di setiap produk berdasarkan tier tingkatan akun Anda.

calculate Rumus Perhitungan Diskon

Harga Reseller = Harga Normal × (1 − Diskon%)

Contoh: Jika harga normal produk adalah Rp100.000 dan tier akun Anda memiliki diskon 5%, maka harga modal yang Anda bayar ke NexShop adalah Rp95.000. Anda bebas menjual di website Anda misalnya seharga Rp99.000 atau Rp100.000.

account_tree Bab 5 (Developer)

Alur Membangun Website Toko Reseller Sendiri

Jika Anda ingin membangun website toko topup atau bot jualan sendiri, berikut adalah arsitektur integrasi standar yang direkomendasikan:

flowsheet Siklus Alur Transaksi Toko Anda

1

Tarik Katalog Produk dari NexShop

Website Anda memanggil API GET /api/topup/catalog atau GET /api/topup/products menggunakan Token Reseller Anda untuk menyimpan & menampilkan daftar produk dan harga modal di database website Anda.

2

Pelanggan Memilih Produk & Memasukkan Data

Pelanggan di website Anda memasukkan User ID Game / No HP / No Rekening. Website Anda dapat memanggil POST /api/topup/check-nickname untuk memverifikasi nama akun game pelanggan secara real-time.

3

Teruskan Pesanan ke API NexShop

Setelah pelanggan membayar ke toko Anda, server Anda memanggil POST /api/topup ke NexShop untuk mengeksekusi pengiriman produk.

4

Terima Callback Webhook Real-time

Server NexShop mengirimkan webhook callback HTTP POST ke URL server Anda saat transaksi sukses/gagal beserta Serial Number (SN) atau Token PLN. Website Anda langsung mengupdate pesanan pelanggan secara instan.

sync_alt Bab 9 (Webhook)

Konsep & Alur Webhook Relay

Layanan Webhook Relay NexShop memungkinkan website atau bot toko Anda menerima notifikasi status transaksi (sukses, gagal, SN resmi) secara instan (real-time push) langsung dari server NexShop ke URL callback endpoint yang Anda daftarkan.

route Routing Berdasarkan Prefix ref_id

Setiap kali membuat order, Anda dapat menyertakan prefix unik pada ref_id (misalnya: MYSTORE-10293). Relay NexShop akan mencocokkan prefix tersebut dan secara otomatis mem-forward callback hanya ke endpoint URL toko Anda.

lock Bab 11 (Webhook)

Verifikasi Signature Kriptografis (HMAC SHA-256)

Rumus tanda tangan: signature = "sha256=" + HMAC_SHA256(secret_anda, timestamp + "." + raw_body)

webhook-handler.js (Node.js Express) JavaScript 
const express = require("express");
const crypto = require("crypto");

const app = express();
const WEBHOOK_SECRET = "whsec_secret_toko_anda";

app.post("/api/webhook/nexshop", express.raw({ type: "application/json" }), (req, res) => {
    const signatureHeader = req.headers["x-nexshop-signature"];
    const timestamp = req.headers["x-nexshop-timestamp"];
    const rawBody = req.body.toString("utf8");

    if (!signatureHeader || !timestamp) {
        return res.status(400).send("Missing signature");
    }

    const expectedSignature = "sha256=" + crypto
        .createHmac("sha256", WEBHOOK_SECRET)
        .update(timestamp + "." + rawBody)
        .digest("hex");

    if (!crypto.timingSafeEqual(Buffer.from(signatureHeader), Buffer.from(expectedSignature))) {
        return res.status(401).send("Invalid signature");
    }

    const payload = JSON.parse(rawBody);
    const trx = payload.data;
    console.log("Status Transaksi:", trx.ref_id, trx.status_message, "SN:", trx.sn);

    // Update status pesanan di database toko Anda & kirim SN ke pembeli
    // ...

    res.status(200).json({ received: true });
});

app.listen(8000, () => console.log("Webhook server running on port 8000"));
callback.php (PHP) PHP 
<?php
$secret = "whsec_secret_toko_anda";
$rawBody = file_get_contents("php://input");
$timestamp = $_SERVER['HTTP_X_NEXSHOP_TIMESTAMP'] ?? '';
$signature = $_SERVER['HTTP_X_NEXSHOP_SIGNATURE'] ?? '';

if (empty($signature) || empty($timestamp)) {
    http_response_code(400);
    exit("Missing signature");
}

$expected = "sha256=" . hash_hmac("sha256", $timestamp . "." . $rawBody, $secret);

if (!hash_equals($expected, $signature)) {
    http_response_code(401);
    exit("Invalid signature");
}

$payload = json_decode($rawBody, true);
$trx = $payload['data'];

// Update pesanan di database toko Anda
http_response_code(200);
echo json_encode(["received" => true]);
main.py (FastAPI) Python 3 
from fastapi import FastAPI, Request, HTTPException, Header
import hmac, hashlib

app = FastAPI()
WEBHOOK_SECRET = "whsec_secret_toko_anda"

@app.post("/api/webhook/nexshop")
async def receive_webhook(
    request: Request,
    x_nexshop_signature: str = Header(None),
    x_nexshop_timestamp: str = Header(None)
):
    if not x_nexshop_signature or not x_nexshop_timestamp:
        raise HTTPException(status_code=400, detail="Missing signature")
    
    raw_body = (await request.body()).decode("utf-8")
    signed_payload = f"{x_nexshop_timestamp}.{raw_body}"
    expected_sig = "sha256=" + hmac.new(
        WEBHOOK_SECRET.encode("utf-8"),
        signed_payload.encode("utf-8"),
        hashlib.sha256
    ).hexdigest()
    
    if not hmac.compare_digest(x_nexshop_signature, expected_sig):
        raise HTTPException(status_code=401, detail="Invalid signature")
    
    payload = await request.json()
    print("Trx update:", payload["data"]["ref_id"], payload["data"]["status_message"])
    return {"received": True}

Contoh Skrip Integrasi Lengkap (Full Starter Flow)

Contoh implementasi pemanggilan API NexShop dari backend toko Anda (Node.js):

nexshop-client.js (Integrasi Lengkap) Node.js 
const axios = require("axios");

const NEXSHOP_BASE = "https://nexshop.cloud/api";
const AUTH_TOKEN = "eyJhbGciOiJIUzI1Ni..."; // Dari login akun reseller

const client = axios.create({
    baseURL: NEXSHOP_BASE,
    headers: {
        "Authorization": `Bearer ${AUTH_TOKEN}`,
        "Content-Type": "application/json"
    }
});

// 1. Ambil Katalog Produk dengan Harga Modal Reseller Anda
async function getKatalog() {
    const res = await client.get("/topup/public-catalog");
    return res.data;
}

// 2. Validasi Akun Game Pelanggan Toko Anda
async function checkGameUser(kodeProduk, userId, serverId) {
    const res = await client.post("/topup/check-nickname", {
        kode_produk: kodeProduk,
        user_id: userId,
        server_id: serverId
    });
    return res.data; // { success: true, nickname: "..." }
}

// 3. Buat Transaksi ke NexShop
async function createOrder(kodeProduk, tujuan, serverId) {
    const res = await client.post("/topup", {
        kode_produk: kodeProduk,
        tujuan: tujuan,
        server_id: serverId,
        payment_method: "qris"
    });
    return res.data; // { success: true, data: { id, total, qr_string } }
}
help Bab 13

Pertanyaan Umum (FAQ Reseller & Developer)

Jawaban atas pertanyaan seputar akun reseller dan integrasi teknis.

Apakah saya bisa menghubungkan website toko / bot Telegram saya ke NexShop?

Bisa! Anda dapat menggunakan API NexShop untuk mengambil katalog harga modal reseller Anda, mengeksekusi order, dan menerima Webhook Callback status transaksi secara real-time.

Bagaimana cara mendaftarkan URL Webhook Callback toko saya?

Hubungi Admin NexShop via WhatsApp dengan menyertakan URL endpoint HTTPS toko Anda (misal: https://tokosaya.com/api/webhook) dan prefix ref_id toko Anda (misal: MYSTORE-). Admin akan mendaftarkan endpoint dan memberikan Webhook Secret key (whsec_...).

Apakah ada batas request (Rate Limit) pada API?

API publik dilindungi rate limiter yang wajar untuk mencegah serangan abuse. Untuk endpoint inquiry tagihan, pastikan memanggil hanya saat pelanggan meminta cek tagihan.

Apakah ada kewajiban deposit saldo minimum?

Tidak ada. Anda bebas melakukan pembayaran per transaksi menggunakan QRIS atau Virtual Account secara real-time.
