FAQ (Pertanyaan yang Sering Diajukan)

iPaymu
Dapatkan VA & API Key di my.ipaymu.com (production) atau sandbox.ipaymu.com (testing) → menu Integrasi.
TokoVoucher
ApiGames
Opsional — kalau diisi, customer bisa "Cek Akun" (nickname) otomatis sebelum topup Mobile Legends & Free Fire. Kalau dikosongkan, fitur ini nonaktif dan customer tetap bisa checkout seperti biasa (tanpa cek otomatis). Dapatkan Merchant ID & Secret Key di apigames.id → menu Pengaturan.
Brevo (Email OTP & Invoice)
Dipakai buat kirim email kode OTP registrasi & invoice pesanan/topup. Ambil API Key di app.brevo.com → SMTP & API. Sender Email harus sudah diverifikasi/authenticated di Brevo (menu Senders & IP), kalau belum, email gagal terkirim walau API Key benar. Kalau email OTP tetap gagal, cek juga menu Users → OTP Aktif buat lihat/kirim ulang kode secara manual.
Google Gemini (Gaming News)
Dipakai untuk merangkum News Import dalam bahasa Indonesia. Bila Gemini tidak tersedia, import tetap memakai fallback metadata.
SMTP (Email)
WA Gateway (Notifikasi WhatsApp)
Dipakai buat kirim notifikasi WhatsApp tiap ada pembelian sukses. Buka waapi.fyas.my.id/dashboard buat generate API Key, lalu isi Nomor Tujuan dengan nomor WA yang mau menerima notifikasi (pakai kode negara, tanpa tanda + atau spasi, mis. 62812xxxxxxxx).
Test Kirim WhatsApp

Kirim pesan percobaan langsung ke gateway WA buat mastiin URL/Key/Nomor di atas sudah bener. Kalau field di atas masih kosong, klik Simpan API Keys dulu, baru test.
